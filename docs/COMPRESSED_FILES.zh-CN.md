# 主程序内置压缩文件

[English](COMPRESSED_FILES.md) | 简体中文

Windows x64 主程序随安装程序携带已校验的原版 7-Zip 26.04 引擎，无需另外安装压缩插件。开发准备命令：`npm run prepare:compression`；打包资源位于 `electron/bin/archive`，安装后位于 `resources/archive`。官方固定版本和下载 SHA-256 见 `electron/services/compressed-files/runtime.lock.json`。许可证随资源携带于 `archive/License.txt`。

旧 `archive-tools` 插件停止贡献菜单，也不能重新启用。完整启动时通过现有组件卸载事务移除用户安装的旧 runtime，保留组件数据（包括未保存输出），不清理历史交付包。该迁移也适用于开发环境中的用户安装副本；其他开发组件的卸载规则不变。

## 文件浏览与面板

- 项目和灵感库的压缩文件使用主程序压缩图标。按当前单击／双击设置打开后，直接把成员提供给现有 `FileBrowserWorkspace`；沿用同一个文件区域、工具栏、面包屑、前进／后退、列表／网格、排序、搜索及 `MediaPreviewPane`，不创建另一套浏览界面。虚拟路径形如 `素材/照片.zip/子目录`，返回原文件夹使用现有导航。
- 目录浏览读取清单，不把整包解压到项目里。缩略图、预览或默认打开时，按需解出单个成员到私有目录。图片／RAW／视频沿用主程序媒体管线（带延迟读取器的内部媒体令牌），1 MiB 以内的文本在原预览面板中显示；其他格式使用默认软件打开。加密内容在打开时提示密码并验证首个加密成员。临时副本的修改不写回原压缩包。
- 包内目录为只读，禁用新建、导入、删除、重命名、粘贴、拖放和写入工具。密码只保留在打开会话内；前进／后退复用会话，页面卸载或会话淘汰时撤销媒体访问令牌并清理临时成员。
- 顶部 Office 菜单提供解压面板；普通文件／文件夹右键提供“添加到压缩文件”，压缩文件右键提供“解压缩”。全部使用主程序 `ToolModal` 和 `TaskProgress`，操作按钮位于进度条右边。
- 压缩面板默认只显示文件名和 ZIP／7z。默认名称使用共同所在文件夹，项目根目录使用项目名称。首次 ZIP，后续通过设置恢复上次格式。压缩等级、密码、分卷、体积上限和注释放入“高级”。7z 禁止注释；ZIP 注释写入原生 ZIP 元数据。
- 解压不提供“高级”或位置选项，需要密码才显示输入框。始终在压缩包旁创建同名目录；名称冲突自动加编号。压缩输出冲突也自动改名，原文件始终保留。分卷和复合扩展名正确去除，如 `照片.7z.001`、`照片.tar.gz`。

## 实现边界

原生入口为 `compressed-files` IPC，只接受主程序应用窗口。上下文通过已绑定项目或配置的灵感库重新解析。渲染端不能指定临时路径、引擎位置或输出绝对路径。原生操作复用主程序已有的输入令牌、私有存储、任务和输出事务实现；内部描述符不进入插件目录，不运行插件服务。

引擎先检查清单，拒绝越界路径、链接、备用数据流、重复大小写路径和不支持的 Windows 名称，最多 2000 个文件和目录。解压／浏览默认体积上限 16 GiB，压缩高级选项可设置 1～64 GiB。输出先暂存校验，再通过事务发布；发布失败保留 stage 和幂等键供“重试保存”。不删除现有的历史插件候选 ZIP。

延迟读取令牌在解出成员后登记物理路径别名，缩略图完成事件同时按虚拟输入令牌发送，原文件条目的订阅可收到排队生成结果。关闭会话撤销令牌与别名。旧主进程未返回媒体输入句柄时明确提示完整重启，禁止把文件伪装成 `archive-directory:` 路径。只刷新开发页面不能更新 Electron 主进程。

为早期插件方案补充的通用 API 按用户要求保留：`selection` 筛选、`contextMenu` 位置、`project.output.stage.maxBytes`、`component.sidePanel.fileHandler.extensions` 与组件图标。文件读取、输入令牌、私有存储、任务和设置是原有能力。详见 `docs/PLUGIN_DEVELOPMENT.md`。

## 验证

`npm run test:compressed-files` 检查真实引擎往返、加密／分卷、目录命名、包内单文件读取、密码、取消、保存恢复及通用插件声明。界面与完整 Electron 集成仍需单独验证。
