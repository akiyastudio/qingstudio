# 导入已有项目

“添加项目 → 导入项目”接受任意普通文件夹，不要求已有 PhotoFlow 项目结构。

- **复制**：复制到工作目录，保留源文件。
- **移动**：复制并校验成功、登记项目后，安全清理源文件。若源文件变化或清理失败，保留源文件并显示提示。
- **引用原位置**：在项目列表中登记原文件夹，以该文件夹自身作为项目物理根目录，不生成快捷方式、不复制素材。文件修改和删除直接作用于原文件夹；修改项目显示名称不会重命名原文件夹。

三种方式均保留文件夹结构，导入时不识别或要求确认素材、版本目录。RAW、JPG、MOV 等名称按普通文件夹处理。用户之后可以主动使用版本管理功能。

引用项目在磁盘离线时保留项目记录，重新连接后恢复访问。禁止重复引用或引用与已登记项目重叠的目录。

素材导入仅复制或移动文件。项目内的文件/文件夹外链创建、重新定位、转入项目、注册表及专用恢复逻辑已正式删除，不提供旧外链迁移。导入外部项目是项目级能力，不是在已有项目内部挂载外部素材目录。

插件访问导入项目时，以该项目登记的物理根目录为边界，使用普通项目相对路径。项目根目录位于工作目录之外不意味着越界；尝试从该项目访问另一外部目录仍会被拒绝。详见 [Host API 项目媒体约定](PLUGIN_HOST_API.md#项目媒体)。

验证命令：`npm run test:project-import`。Windows 原生移动测试需要能够检查临时目录祖先的文件身份。
